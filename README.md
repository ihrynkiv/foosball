# Verity Foosball

A static website for the Verity office table football championship.

- 7 players, 21 matches, 2 vs 2.
- Each player plays 12 matches.
- Each pair of players is a team 2 times and opponents 4 times.
- The winning team gets 1 point for each member.

Open `index.html` in a browser to use the site. Results save in the browser.
